AUDIO SETUP I USE

DJI Mic Mini + OBS Studio

My desktop workflow uses the DJI Mic Mini receiver connected to the PC over USB. The values below are my starting point—not universal settings. Room noise, mic distance, voice, and Windows input level all affect the result.

Read the full mic guide
01

Connect the receiver

Connect the DJI receiver (RX) to the desktop by USB, select it as the OBS Mic/Aux input, and set OBS audio to 48 kHz. Use Stereo when it suits your routing, and disable unused Desktop Audio sources.

02

My OBS filter chain

RNNoise → Expander (3:1, −45 dB threshold) → 3-band EQ (high +2, mid −2, low +2) → Compressor (3:1, −18 dB threshold, +4 dB output) → Gain (+15 dB) → Limiter (−1 dB, 60 ms release).

03

Test before going live

Record a short sample and listen on headphones. Watch for clipping, pumping, room noise, and harshness. The +15 dB gain is specific to my setup and may be too much for yours.

My practical takeaway: I prefer keeping a receiver connected to the desktop for OBS and using the appropriate mobile receiver/adapter setup for the phone, rather than constantly swapping one setup around. Keep a USB desk mic such as the HyperX SoloCast as a backup if you already own one.

Buying note: A full kit with transmitters, receiver, and charging case is the most flexible starting point for someone who needs both desktop and mobile use. Check the exact receiver and Lightning adapter compatibility before ordering; the newer DMMR02 mobile receiver requires the matching DJI Mic Series USB-C-to-Lightning adapter, not the older Mic Mini Lightning adapter.
