Using images from GitHub

  1. Create a public repository, such as my-model-profile-assets.
  2. Upload photos into an images folder and commit them.
  3. Open an image and select Raw.
  4. Paste the direct URL into Profile image URL.

Example: https://raw.githubusercontent.com/USERNAME/REPO/main/images/profile.jpg
