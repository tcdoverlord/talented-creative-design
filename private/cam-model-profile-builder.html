3. Host profile images on GitHub

  1. Sign in to GitHub and create a public repository, for example my-model-profile-assets.
  2. Choose Add file → Upload files. Upload your profile photo and banners, preferably in an images folder, then commit.
  3. Open an image in the repository and choose Raw to get the direct image URL.
  4. Paste that URL into the image field. It should look like this:
https://raw.githubusercontent.com/USERNAME/REPOSITORY/BRANCH/images/your-image.jpg
Privacy: Anything in a public repository can be viewed and downloaded by anyone. Don't upload identity documents, private information, location clues, or images you don't have permission to publish.
