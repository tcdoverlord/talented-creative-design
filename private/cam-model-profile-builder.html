📦 Publish your ZIP pack on GitHub Pages

  1. Click Download Website ZIP Pack. The ZIP contains index.html, README.md, and an assets folder when you include a local image.
  2. Open GitHub and create a new public repository. Give it a simple name, such as my-model-profile.
  3. Extract the ZIP on your computer. Open the extracted folder and upload its contents to the repository root—not the ZIP file and not an extra enclosing folder.
  4. Commit the files. In the repository, open Settings → Pages.
  5. Under Build and deployment, choose Deploy from a branch, select main and /(root), then save.
  6. Wait for GitHub Pages to finish publishing. Your site address will appear in Settings → Pages, usually as https://USERNAME.github.io/REPOSITORY/.
Privacy: A public repository and published website can be viewed and copied by anyone. Only upload images and information you intend to make public. Do not upload ID documents, private information, or location clues.
