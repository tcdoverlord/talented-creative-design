HOW IT WORKS

A simple, safety-first workflow.

The intended process guides the user from selecting a drive to confirming its removal.

1

Select

2

Follow the prompts

Start the process and follow any Windows safe-removal messages.

3

Confirm removal

Disconnect only when it is safe, and let the app detect the drive's removal.

!
SAFETY REMINDER

Never unplug a busy drive.

Save your work and close files or applications that may be using the USB drive. If Windows reports that the drive is still in use, resolve the issue before disconnecting it.
